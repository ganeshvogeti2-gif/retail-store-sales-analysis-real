Data-cleaning and analysis note

The Analysis page reads the SQLite-synchronized CSV with Pandas, removes exact duplicates, parses dates, repairs derivable missing numeric values, writes a cleaned CSV, and builds category/month summaries. It includes a category-by-month heatmap and NumPy year-over-year growth when multiple years exist. New sales can record optional customer ID, discount and location metadata; older sample sales remain unchanged.

01 · OVERVIEW

Retail Store Sales Analysis

RetailIQ is a local retail store owner and manager system for managing products, recording sales, monitoring low stock and understanding sales patterns. It is intentionally simple: the application uses a Flask server, a local SQLite database and familiar data-analysis libraries.

Project objective

Convert day-to-day store records into clear, useful information for inventory and sales decisions without requiring a complex enterprise system.

Core features

  • Signup, login and logout using Flask sessions and hashed passwords.
  • Product add, search, edit and delete operations backed by SQLite.
  • Sale recording with automatic total calculation and stock reduction.
  • Searchable sales history with date filters and sorting.
  • Pandas aggregation, NumPy statistics and four Matplotlib charts.

03 · DATA FLOW

SQLite → Pandas → NumPy → Matplotlib

Live sales are stored in SQLite. The analysis module reads the joined sales and product rows into a Pandas DataFrame, groups and sorts the data, uses NumPy arrays for numerical statistics, and sends the resulting values to Matplotlib. Flask then serves the generated chart files to the dashboard and analysis page.

SQLite→Pandas→NumPy→Matplotlib→Flask + HTML
04 · BUSINESS RULES

Stock and sales calculations

  • Sale total: product price × quantity.
  • Stock update: current stock − quantity sold, performed in the same database operation flow.
  • Low stock: a product is low stock when stock_quantity ≤ reorder_level.
  • Average sale: NumPy mean of the total amount array.
  • Top products: Pandas grouping by product name, summed total amount and sorted descending.
  • Monthly sales: the sale date is converted to a month period, then revenue is grouped by month.

Limitations and future scope

This is a local single-store project. It does not include multi-user permissions, cloud hosting, purchase orders, barcode scanning, supplier management or online payments. A future version could add role-based access, exports, automated restock suggestions and a production database.

05 · VIVA PREP

Simple questions and answers

Why did you use SQLite?

SQLite is lightweight, serverless and stored in one local file, which makes it reliable and easy to demonstrate for a college project.

Why are Pandas and NumPy both used?

Pandas is used for tabular data operations such as grouping and aggregation. NumPy is used for numerical arrays and statistics such as mean, minimum and maximum.

How do you prevent negative stock?

The sale route checks the requested quantity against current stock before inserting the sale. The database update only runs after the validation passes.

What happens after a sale is recorded?

The sale row is inserted with the calculated total, the product stock is reduced, and the dashboard and analysis pages read the changed database values on their next request.
